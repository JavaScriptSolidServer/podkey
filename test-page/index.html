What is Podkey?

Podkey is a browser extension that provides NIP-07 wallet functionality for the Nostr protocol. It enables seamless authentication to Solid pods using did:nostr decentralized identifiers. Your cryptographic keys stay secure in your browser, giving you full control over your identity and data.

📋 Prerequisites: You'll need Node.js (v18+) and Git installed. Download Node.js | Download Git

Step-by-Step Installation

  1. Step 1: Clone the Repository
    Open your terminal and run:
    git clone https://github.com/JavaScriptSolidServer/podkey.git
  2. Step 2: Navigate and Install Dependencies
    Enter the directory and install required packages:
    cd podkey
    npm install
  3. Step 3: Build the Extension
    Compile the extension for browser use:
    npm run build
    ✓ This creates src/background.bundle.js
  4. Step 4: Load Extension in Chrome/Edge
    Follow these steps in your browser:
    • Open chrome://extensions/ (or edge://extensions/ for Edge) in a new tab
    • Enable "Developer mode" using the toggle in the top-right corner
    • Click the "Load unpacked" button that appears
    • Navigate to and select the podkey directory (the one containing manifest.json)
  5. Step 5: Verify Installation
    Reload this page (F5 or Ctrl+R) and the extension should be detected! You'll see a green checkmark above and can start testing Podkey's features.

✅ First Time Setup: After installation, click the Podkey extension icon in your browser toolbar to generate or import your first keypair. This creates your did:nostr identity!

🔧 Troubleshooting:

  • Extension not detected? Make sure you reloaded this page after installation
  • Build errors? Ensure Node.js v18+ is installed: node --version
  • Can't find "Load unpacked"? Developer mode must be enabled first
  • Extension icon not showing? Check chrome://extensions/ to ensure it's enabled
