Install Podkey

Podkey provides NIP-07 signing for Nostr and authenticates to Solid pods using did:nostr identifiers. Your cryptographic keys stay in your browser — you stay in control of your identity and data.

Quick install

  1. Download the extension
    Grab the latest packaged release, or the source ZIP from the repository.
    Download latest release
  2. Build, if you downloaded source
    Requires Node.js 18+. 
    cd podkey
npm install
npm run build
  3. Load it in Chrome or Edge
    • Open chrome://extensions (or edge://extensions).
    • Enable Developer mode (top-right).
    • Click Load unpacked.
    • Select the podkey folder containing manifest.json.
  4. Verify
    Reload this page. The status above turns green when the extension is detected, and these tests become live.
First run: open the Podkey icon in your toolbar to generate or import your first key — that creates your did:nostr identity.
Learn more: repository, did:nostr spec, Solid Project, NIP-07.
Troubleshooting:
  • Not detected? Reload this page after loading the extension.
  • Build errors? Check node --version is 18+.
  • No “Load unpacked”? Enable Developer mode first.
